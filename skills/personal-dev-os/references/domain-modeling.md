# Domain Modeling Standard

Agent operational excerpt. Human SSOT also: `~/Agent Engineering OS/30-Patterns/domain-modeling-standard.md`.

- One canonical term per domain concept.
- List avoided synonyms when they cause confusion.
- Keep definitions short: what the concept is, not implementation mechanics.
- Use `CONTEXT.md` for domain language; `CONTEXT-MAP.md` when multiple bounded contexts exist.
- Create context docs lazily when terms are actually resolved.
