# Reliability And Operations

Read for production services, jobs, queues, external dependencies, streaming, data processing, and user-critical workflows.

- Define user-facing SLI/SLO for critical paths when reliability matters.
- Specify timeout, retry/backoff, rate limit, circuit breaking, deduplication, degradation, and capacity behavior.
- Make logs structured, correlated, actionable, and redacted; measure volume, errors, latency percentiles, saturation, queue depth, and dependency failures.
- Use symptom-based, actionable alerts with an owner and runbook.
- Define rollback, kill switch, feature flag, or degraded mode before risky release.
- For incidents, record impact, timeline, causes, corrective actions, owners, and follow-up.
